# ふしまる 🎤

好きな曲の音源を読み込むと、ガイドメロディ（音程バー）を自動で推定し、カラオケのように歌を採点するWebアプリです。

- 公開版: https://fushimaru.vercel.app
- 採点項目: 音程60%・安定性15%・リズム15%・表現力10%。点数は小数3桁まで出します
- 音声はすべてブラウザ内で処理し、外部には送りません

## つかいかた

1. 音源ファイル（mp3 / m4a / wav など）を選ぶ。お試し用にデモ曲「きらきら星」も入っています
2. ガイドメロディの推定を待つ（Web Workerで処理）
3. 「歌う」を押してマイクを許可し、流れてくる音程バーに合わせて歌う。イヤホンの使用を推奨します
4. 曲が終わるか「ここで採点」を押すと結果が出る

伴奏は「原曲」と「ボーカル控えめ」（左右の差分をとって中央の声を消す簡易ボーカルカット）から選べます。ガイド音の音量も変えられます。

## しくみ

| 段階 | やっていること | ファイル |
|---|---|---|
| ガイド推定 | 左右の一致度から中央に定位した音を強調 → 倍音の重み付き和で基本周波数の候補を出す → 動的計画法で急に飛ばない経路を選ぶ → 音量の谷で同じ高さの連続音を分け、音符にまとめる | `src/lib/melody.js` |
| 声の音程 | AudioWorkletで2048サンプルの窓をため、YINで音程を推定 | `public/mic-worklet.js`, `src/lib/pitch.js` |
| 採点 | 1オクターブ違いは正解扱い。機器の遅れ（-0.2〜+0.45秒）は全体をずらして最もよく合う位置を探して補正する。音程が合っていない歌には、安定性・リズム・表現力の点も入らないようにしている（音程ゲート） | `src/lib/score.js` |

- **安定性**: 0.5秒以上伸ばした音について、ゆっくりした揺れと細かいふらつきを見ます。ビブラートは減点しません
- **リズム**: 各音の歌い出しの時刻を見ます。0.06秒以内のずれは満点、0.3秒ずれると0点です
- **表現力**: 声の抑揚（dB幅）、ビブラートの回数、しゃくりの回数から決めます

## 開発

```bash
pnpm install
pnpm dev     # http://localhost:5820
pnpm test    # Vitest（採点の公平性・メロディ推定・YIN）
```

`window.__app.simulate({ shift, delay })` を使うと、マイクの代わりに合成した歌声で採点できます（ヘッドレス環境での確認用）。

## 限界

- 伴奏が大きい曲やコーラスが厚い曲では、ガイドの推定がずれることがあります。ボーカルだけの音源を使うと精度が上がります
- 家庭用カラオケのような公式の音程データは使っていないので、点数はあくまで目安です
